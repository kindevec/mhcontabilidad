## Formato para una nueva decisión

### ADR-0001 — Título claro (ejemplo de formato, NO decisión tomada)
- **Fecha:** AAAA-MM-DD
- **Estado:** Propuesta / Aceptada / Rechazada / Sustituida
- **Contexto y problema:** ¿Qué se necesita decidir?
- **Opciones consideradas:** Alternativas reales y sus pros/contras.
- **Decisión y razón:** Qué se eligió y por qué.
- **Consecuencias:** Beneficios, costos, riesgos y migraciones necesarias.
- **Evidencia:** Issues, commits, PRs, pruebas, documentación.
- **Sustituye / sustituida por:** ID si aplica.
